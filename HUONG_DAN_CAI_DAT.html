Bước 1: AI Hướng Dẫn Lấy Blogger Blog ID & URL

Thao tác 10 giây trên trình duyệt:

2

Bước 2: AI Cung Cấp Link Lấy Gemini AI API Key Miễn Phí

Mã khóa trí tuệ nhân tạo viết bài chuẩn SEO:

  • AI gửi link trực tiếp: Google AI Studio API Keys.

Bước 3: AI Hướng Dẫn Tạo Bản Sao Google Sheets Đề Tài

Quản lý hàng trăm bài viết thuận tiện ngay trên điện thoại:

  • AI gửi đường link 1-click tạo bản sao bảng tính chuẩn: Tạo Bản Sao Google Sheets Mẫu.
  • Bạn bấm Tạo bản sao ➔ Bấm nút Chia sẻ (Share) ở góc trên bên phải ➔ Chuyển quyền thành "Bất kỳ ai có đường liên kết đều có thể xem/chỉnh sửa".

4

Bước 4: AI Hướng Dẫn Bấm 4 Thao Tác Trên Google Cloud (Client ID & Secret)

Cấp quyền đăng bài Blogger thông qua Google OAuth 2.0:

  • AI hướng dẫn vào Google Cloud Console tạo Project.
  • Bật Blogger API v3 trong thư viện API Library.
  • Tại OAuth Consent Screen: Chọn External, thêm Gmail của bạn vào mục Test users, bấm Publish App để không hết hạn sau 7 ngày.
  • Tại mục Credentials: Tạo OAuth Client ID dạng Desktop app ➔ Gửi Client ID & Client Secret cho AI.
5

Bước 5: Lấy Blogger Refresh Token (AI Kích Hoạt Tự Động)

Cấp quyền vĩnh viễn chỉ bằng 1 cú nhấp chuột:

  • Trợ lý AI sẽ tự động kích hoạt tiến trình xác thực ủy quyền. Trình duyệt trên máy bạn tự động mở trang đăng nhập Google.
  • Bạn chọn tài khoản Gmail quản lý Blog ➔ Bấm Nâng cao (Advanced) ➔ Bấm Chuyển đến [Tên App] (không an toàn) ➔ Bấm Cho phép (Allow).
  • Sau khi bạn bấm xong, AI tự động thu nhận và lưu mã Refresh Token vào hệ thống!

2

BẬT QUYỀN CHIA SẺ CÔNG KHAI (BƯỚC QUAN TRỌNG NHẤT)

Mặc định bảng tính Google Sheets ở chế độ Riêng tư, bot đám mây sẽ không thể đọc dữ liệu đề tài nếu bạn chưa mở quyền xem:

  1. Ở góc trên bên phải bảng tính Google Sheets, bấm vào nút màu xanh Chia sẻ (Share).
  2. Ở mục Quyền truy cập chung (General access), đổi từ Hạn chế (Restricted) sang: Bất kỳ ai có đường liên kết đều có thể xem (Anyone with the link can view).
  3. Bấm nút Sao chép đường liên kết (Copy link) ➔ Bấm Xong.
⚠️
CẢNH BÁO LỖI PHỔ BIẾN: Nếu bạn quên bật quyền này, khi bot chạy sẽ báo lỗi "Google Sheets trả về trang HTML Đăng nhập tài khoản" và không thể lấy đề tài để đăng bài!
3

Gắn Link Google Sheets Vào Cấu Hình

Dán đường link vừa sao chép vào hệ thống của bạn:

  • Nếu dùng trên máy tính (Local): Mở file .env và dán link vào biến:
    GOOGLE_SHEET_URL=https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit#gid=0
  • Nếu dùng trên mây GitHub Actions: Vào Repository ➔ Settings ➔ Secrets and variables ➔ Actions ➔ Tạo Secret mới có tên là GOOGLE_SHEET_URL và dán link vào ô Value.
4

(Tùy chọn nâng cao) Cài Webhook Tự Động Cập Nhật Ngược Lại Sheet

Để Google Sheet tự động nhảy màu xanh "Đã đăng" và tự dán link bài viết vào Cột I, bạn chỉ mất 2 phút thiết lập Webhook Google Apps Script có sẵn:

  1. Trên bảng tính Google Sheets, vào menu Tiện ích mở rộng (Extensions) ➔ Chọn Apps Script.
  2. Xóa sạch code mẫu có sẵn trong trình soạn thảo.
  3. Mở file google_sheets_webhook.js có sẵn trong thư mục mã nguồn ➔ Sao chép toàn bộ nội dung và dán vào Apps Script.
  4. Bấm nút Lưu dự án (Biểu tượng đĩa mềm 💾).
  5. Bấm nút xanh Triển khai (Deploy) ở góc trên bên phải ➔ Chọn Bản triển khai mới (New deployment):
    • Chọn loại: Bấm biểu tượng bánh răng ⚙️ ➔ Chọn Ứng dụng web (Web app).
    • Mô tả: Điền Blogger Webhook Auto.
    • Thực thi dưới dạng: Tôi (Email của bạn).
    • Người có quyền truy cập (Who has access): BẮT BUỘC CHỌN Bất kỳ ai (Anyone).
  6. Bấm Triển khai (Deploy) ➔ Nếu Google yêu cầu cấp quyền truy cập, bấm Xem xét quyền (Review Permissions) ➔ Chọn tài khoản Gmail ➔ Bấm Nâng cao (Advanced) ➔ Bấm Đi tới dự án (không an toàn) ➔ Bấm Cho phép (Allow).
  7. Sao chép đường link URL ứng dụng web (Web App URL) (có dạng kết thúc bằng /exec).
  8. Dán link này vào biến GOOGLE_SHEET_WEBHOOK_URL trong file .env (hoặc tạo thêm 1 Secret trên GitHub Actions).
🎉

1. Thiết Lập Tài Khoản Blogger & 2 Cài Đặt SEO Bắt Buộc

Nếu bạn chưa có trang Blog, hãy tạo mới trong 30 giây:

  1. Truy cập: blogger.com và đăng nhập bằng tài khoản Google của bạn.
  2. Nếu là tài khoản mới tinh: Hệ thống sẽ yêu cầu bạn nhập Tiêu đề blog (vd: Tin Tức Doanh Nghiệp) ➔ Nhập Địa chỉ URL (vd: doanhnghiep2026.blogspot.com) ➔ Nhập Tên hiển thị tác giả ➔ Bấm Hoàn tất.
⚙️
2 CÀI ĐẶT BẮT BUỘC TRÊN BLOGGER (RẤT NHIỀU NGƯỜI BỎ QUÊN):
1. Bật Thẻ Meta Mô Tả Tìm Kiếm: Vào menu bên trái chọn Cài đặt (Settings) ➔ Cuộn xuống mục Thẻ meta (Meta tags) ➔ BẬT công tắc: Bật nội dung mô tả tìm kiếm (Enable search description). (Nếu không bật, bài viết AI sẽ bị mất phần mô tả tóm tắt chuẩn SEO trên Google!).
2. Đổi Múi Giờ Việt Nam (GMT+07:00): Vẫn trong Cài đặt, cuộn xuống mục Định dạng (Formatting) ➔ Bấm vào Múi giờ (Time zone) ➔ Chọn: (GMT+07:00) Giờ Đông Dương (Hà Nội, Băng Cốc, Jakarta). (Mặc định Blogger để giờ Mỹ, nếu không đổi bài hẹn giờ Khung Giờ Vàng 06:30, 11:30 sẽ bị lệch hoàn toàn!).

Cách lấy BLOGGER_BLOG_ID:

Nhìn lên thanh địa chỉ (URL) trình duyệt khi đang ở trang quản trị Blog:

https://www.blogger.com/blog/posts/1234567891011121314

Dãy số phía sau chữ posts/ (ví dụ: 1234567891011121314) chính là BLOGGER_BLOG_ID của bạn.

2. Khóa Google Gemini AI API Key (Miễn phí 100%)

Gemini AI là "bộ não" viết bài chuẩn SEO tiếng Việt dài 1.500 - 2.500 từ theo công thức chuyển đổi cao CRO.

  1. Truy cập Google AI Studio: aistudio.google.com/app/apikey.
  2. Đăng nhập tài khoản Google của bạn. Nếu là lần đầu tiên, hãy tích chọn đồng ý với Điều khoản dịch vụ (Terms of Service) rồi bấm Continue.
  3. Bấm nút xanh: Create API Key (hoặc Get API key).
  4. Chọn Create API key in new project (Tạo trong dự án mới).
  5. Sao chép chuỗi mã bắt đầu bằng AIzaSy... và lưu lại. Đó là GEMINI_API_KEY.
💡
Mẹo Key Pool xoay vòng: Hạn ngạch miễn phí của Google là 15 yêu cầu/phút. Bạn có thể dùng 2 - 3 Gmail phụ tạo thêm key và dán cách nhau bằng dấu phẩy vào biến GEMINI_API_KEYS để hệ thống tự động luân chuyển khi chạy nhiều bài liên tục!

3. Google Cloud OAuth (Client ID, Secret & Refresh Token Vĩnh Viễn)

Cấp chứng chỉ bảo mật cho robot tự động đăng bài lên Blogger thay mặt bạn.

A

Tạo Dự Án & Bật Blogger API v3

1. Vào console.cloud.google.com ➔ Bấm Select a project ở góc trên bên trái ➔ Bấm New Project ➔ Đặt tên (vd: Blogger-Auto) ➔ Bấm Create.
2. Vào thanh tìm kiếm trên cùng gõ: Blogger API v3 ➔ Bấm vào kết quả ➔ Bấm nút xanh Enable (Bật).

B

Cấu hình OAuth Consent Screen & Thêm Test User

1. Ở menu bên trái, vào APIs & Services ➔ Chọn OAuth consent screen.
2. Chọn loại người dùng: External (Bên ngoài) ➔ Bấm Create.
3. Điền App name (vd: Blogger Bot), chọn email của bạn ở các ô Email hỗ trợ và Email liên hệ nhà phát triển ➔ Bấm Save and continue.
4. Ở bước Scopes: Bấm Save and continue.
5. BƯỚC BẮT BUỘC Ở MỤC TEST USERS: Bấm nút + Add users ➔ Điền chính địa chỉ Gmail bạn dùng quản lý Blogger vào ➔ Bấm Save and continue. (Nếu không thêm, khi đăng nhập sẽ bị lỗi: Error 403: access_denied).

★

BÍ KÍP VÀNG: Bấm "Publish App" Chống Hết Hạn Token Sau 7 Ngày!

Theo chính sách của Google, nếu ứng dụng ở trạng thái Testing, Refresh Token sẽ tự động bị hủy sau 7 ngày, khiến hệ thống bị báo lỗi invalid_grant.
👉 CÁCH GIẢI QUYẾT VĨNH VIỄN: Vẫn trong màn hình OAuth consent screen, ngay dưới dòng Publishing status (Testing), bấm vào nút PUBLISH APP (Xuất bản ứng dụng) ➔ Bấm Confirm (Xác nhận). Trạng thái sẽ chuyển sang In production. Token của bạn sẽ TỒN TẠI VĨNH VIỄN KHÔNG BAO GIỜ HẾT HẠN!

C

Tạo Thông Tin Xác Thực (Desktop App)

1. Ở menu bên trái, chọn mục Credentials (Thông tin xác thực).
2. Bấm nút + Create Credentials ở trên cùng ➔ Chọn OAuth client ID.
3. Mục Application type: BẮT BUỘC CHỌN Desktop App (Ứng dụng cho máy tính để bàn). (Tuyệt đối không chọn Web Application).
4. Bấm Create. Google sẽ hiển thị bảng chứa Client ID và Client Secret. Sao chép 2 mã này lưu lại.

D

Lấy Refresh Token 1-Click & Vượt Màn Hình Cảnh Báo

1. Bấm đúp chạy file LAY_REFRESH_TOKEN.bat trên máy tính của bạn (hoặc để Setup Wizard tự chạy).
2. Dán Client ID và Client Secret vào theo yêu cầu.
3. Trình duyệt web sẽ tự động mở trang đăng nhập Google.
4. VƯỢT MÀN HÌNH BẢO MẬT: Google sẽ hiện thông báo "Google chưa xác minh ứng dụng này" (Google hasn't verified this app). Đừng lo lắng! Hãy bấm vào chữ Nâng cao (Advanced) ở góc dưới bên trái ➔ Bấm vào liên kết Chuyển đến [Tên ứng dụng] (không an toàn) ➔ Tích chọn quyền quản trị Blogger ➔ Bấm Tiếp tục / Cho phép (Allow).
5. Chuỗi mã dài bắt đầu bằng 1//0... chính là GOOGLE_REFRESH_TOKEN, script sẽ tự động lưu thẳng vào file .env cho bạn!

❓ Câu Hỏi Thường Gặp & Xử Lý Sự Cố Toàn Diện (FAQ)

Bấm vào từng câu để xem hướng dẫn chi tiết
1. Tại sao hệ thống chạy được 7 ngày thì lăn ra báo lỗi "invalid_grant"? ▼
Nguyên nhân: Theo chính sách của Google Cloud, khi màn hình OAuth consent screen của bạn đang ở trạng thái "Testing", mã Refresh Token cấp cho ứng dụng chỉ có hạn sử dụng đúng 7 ngày!
Cách xử lý vĩnh viễn: Truy cập console.cloud.google.com ➔ Chọn đúng Project ➔ Vào OAuth consent screen ➔ Ngay dưới dòng Publishing status, bấm nút PUBLISH APP (Xuất bản ứng dụng) ➔ Bấm Confirm. Trạng thái chuyển sang In production. Sau đó chạy lại LAY_REFRESH_TOKEN.bat lấy mã mới dán vào .env (hoặc GitHub Secrets). Token sẽ sống VĨNH VIỄN KHÔNG BAO GIỜ BỊ HẾT HẠN!
2. Báo lỗi "Error 403: access_denied" khi đăng nhập OAuth lấy Token? ▼
Nguyên nhân: Bạn chưa thêm địa chỉ Gmail của mình vào danh sách người dùng thử nghiệm (Test users) trên Google Cloud.
Cách xử lý: Vào console.cloud.google.com ➔ OAuth consent screen ➔ Kéo xuống mục Test users ➔ Bấm nút + ADD USERS ➔ Điền chính xác địa chỉ Gmail bạn dùng quản lý Blogger vào ➔ Bấm Save. Sau đó chạy lại file lấy token là sẽ đăng nhập mượt mà!
3. Màn hình Google cảnh báo "Google chưa xác minh ứng dụng này" (Google hasn't verified this app)? ▼
Giải thích: Đây là cơ chế cảnh báo an toàn bình thường của Google đối với các ứng dụng nội bộ do cá nhân tự lập trình. Ứng dụng này hoàn toàn an toàn 100% vì do chính bạn tạo trong tài khoản Google Cloud của mình.
Cách vượt qua: Tại màn hình cảnh báo, nhìn xuống góc dưới bên trái bấm vào chữ Nâng cao (Advanced) ➔ Bấm vào liên kết nhỏ Chuyển đến [Tên App] (không an toàn) ➔ Tích chọn ủy quyền quản trị Blogger ➔ Bấm Tiếp tục / Cho phép (Allow).
4. Tại sao bài đăng lên Blogger bị mất ô "Mô tả tìm kiếm" (Search Description chuẩn SEO)? ▼
Nguyên nhân: Mặc định đối với các trang Blogger mới lập, tính năng Mô tả tìm kiếm đang BỊ TẮT trong phần cài đặt của Blogger.
Cách xử lý: Mở trang quản trị Blogger ➔ Vào mục Cài đặt (Settings) ở cột trái ➔ Cuộn xuống mục Thẻ meta (Meta tags) ➔ BẬT công tắc: Bật nội dung mô tả tìm kiếm (Enable search description). Kể từ bài sau, tóm tắt SEO của AI sẽ tự động điền chuẩn xác!
5. Tại sao bài viết hẹn giờ (Khung Giờ Vàng) bị đăng sai giờ hoặc đăng vào ban đêm? ▼
Nguyên nhân: Blogger mới tạo thường mặc định cài múi giờ Thái Bình Dương của Mỹ (GMT-07/GMT-08), trong khi bot lên lịch vào 06:30, 11:30, 14:30 theo giờ Việt Nam.
Cách xử lý: Vào trang quản trị Blogger ➔ Cài đặt (Settings) ➔ Cuộn xuống phần Định dạng (Formatting) ➔ Bấm vào Múi giờ (Time zone) ➔ Chọn: (GMT+07:00) Giờ Đông Dương (Hà Nội, Băng Cốc, Jakarta) ➔ Lưu lại.
6. Đưa lên GitHub xong vào tab Actions thấy TRỐNG TRƠN, không có workflow nào? ▼
Nguyên nhân: Trên máy tính Windows, thư mục .github là thư mục ẩn. Khi bạn kéo thả file lên web GitHub, trình duyệt đã bỏ sót thư mục này, dẫn đến thiếu file .github/workflows/auto_post.yml.
Cách xử lý: Hãy chạy file DONG_GOI_FILE_ZIP.bat trên máy tính để tạo file Blogger_Auto_Cloud_Tron_Goi.zip. Sau đó giải nén ra một thư mục mới và tải tất cả lên GitHub, đảm bảo có đủ thư mục .github!
7. GitHub Actions chạy bị báo lỗi đỏ "403 Permission to repository denied to github-actions[bot]"? ▼
Nguyên nhân: Bạn chưa cấp quyền GHI (Write) cho máy ảo GitHub Actions để nó lưu lịch sử posted_history.json.
Cách xử lý: Trên GitHub Repository, vào Settings ➔ Cột trái chọn Actions ➔ General ➔ Cuộn xuống mục Workflow permissions ➔ Tích chọn: Read and write permissions ➔ Bấm Save.
8. Đồng bộ đề tài Google Sheets bị lỗi hoặc báo trả về trang HTML đăng nhập? ▼
Nguyên nhân: File Google Sheet của bạn đang để ở chế độ Riêng tư (Chỉ mình bạn xem được), bot không thể đọc dữ liệu đề tài.
Cách xử lý: Mở bảng tính Google Sheets của bạn ➔ Bấm nút Chia sẻ (Share) màu xanh ở góc trên bên phải ➔ Ở mục Quyền truy cập chung, đổi từ "Hạn chế" sang: Bất kỳ ai có đường liên kết đều có thể xem (Anyone with the link can view) ➔ Bấm Xong.
9. Tại sao GitHub Actions sau 60 ngày tự nhiên bị tạm dừng không chạy lịch cron nữa? ▼
Giải thích: GitHub có chính sách tiết kiệm tài nguyên: Nếu một Repository không có bất kỳ commit code nào trong 60 ngày liên tục, các lịch chạy tự động (cron) sẽ tạm thời nghỉ ngơi.
Cách xử lý: Rất đơn giản, khi nhận được email thông báo từ GitHub hoặc thấy bài ngừng đăng, bạn chỉ cần vào tab Actions trên GitHub và bấm nút Enable workflow là hệ thống sẽ ngay lập tức hoạt động lại bình thường!
10. Bấm file .bat bị tắt ngấm hoặc báo "Python is not recognized"? ▼
Nguyên nhân: Máy tính chưa cài Python hoặc khi cài chưa tích chọn ô Add python.exe to PATH.
Cách xử lý: Tải lại Python từ python.org, chạy file cài đặt, chọn Modify (hoặc gỡ cài lại) và nhớ tích chọn ô vuông Add python.exe to PATH ở góc dưới màn hình đầu tiên.
